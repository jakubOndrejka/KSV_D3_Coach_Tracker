# Apps Script backend

Copy `Code.gs` into a Google Apps Script project bound to the Google Sheet used as the tracker database.

Run `initializeProject()` once from the editor, then configure Script Properties and deploy as a Web App. Full instructions are in `../SETUP.md`.

`appsscript.json` is included as a reference manifest. You do not need to replace your manifest manually unless you want the explicit timezone / URL allowlist shown there.
